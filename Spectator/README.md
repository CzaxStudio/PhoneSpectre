# PhoneSpectre

**PhoneSpectre** is a legal phone number OSINT tool for Kali Linux.

## Features
- Phone number validation
- Country & carrier lookup
- Timezone detection
- Line type analysis
- Spam risk heuristic
- JSON export
- 100% legal OSINT

## Installation
```bash
git clone https://github.com/YOURNAME/phonespectre
cd phonespectre
chmod +x install.sh
./install.sh

Usage
phonespectre +14155552671
phonespectre +919876543210 -o report.json
